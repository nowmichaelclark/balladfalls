# The dummy build's additions and removals (queue items 105 and 105e)

`cargo test --features dummy --test dummy` builds the core with these files
laid over `data/` (`build.rs`, `laid_over`), as a later version would change
it, at `newest = 3` with `released = 2`:

- **Joined at 3:** a profile, a mode, a bass style, a voice in each layer, a
  vibe, a mood, an option of glass, a choice drawn alone, a fourth word of
  lowBell's kind, and a setting drawn per loop and counted against a loop's
  changes (the few members the core writes in Rust are behind the feature).
- **Taken out, as rows alone:** one of each kind a code names, with a
  stand-in and without.
- **Narrowed:** fields whose rows hold more than they take today.

`tests/dummy.rs` shows every generation golden drawn at version 2 is bit for
bit what it was, a version 3 loop draws each addition, and a version 2 code
naming what was taken out reads and plays something close. Nothing else ever
builds with them.
