# Share codes, version 2 (queue item 105): every name a code can carry, its
# number in a code, and the version it joined. The format itself is in
# core/README.md, "Share codes"; core/src/code.rs writes and reads it, and
# core/build.rs compiles this file in.
#
# The rules, for whoever adds or removes something (Mikey, 2026-11-10: an
# addition leaves old codes as they sound; 2026-11-17: no code rot, so no
# code ever grows to keep an older one's sound). core/tests/codes.rs and the
# dummy build (core/tests/dummy/) hold them.
#
# Every row is `name id since`, or for a member taken out
# `name id since gone` or `name id since gone stand-in`.
#
# - **Ids are forever.** The id is the name's number in a code, given once
#   and never changed, reused or taken back, whatever happens to the list's
#   order elsewhere. A new member takes the next free id of its list. A
#   member renamed keeps its id. **No row is ever deleted:** every id ever
#   given is in this file, so an id with a row is this build's (gone or
#   not) and an id with none a newer build's.
# - **`since` is the version it joined, and a release has one version.** A
#   new member's `since` is `released + 1`, and `newest` is set to that in
#   the same change: every member added between two releases shares it, so a
#   code made on a build between releases may change as another joins
#   (Mikey, 2026-11-18). A release sets `released = newest`, and nothing
#   else moves either. A code's head is one character to version 15.
# - **Every draw is filtered by the loop's version.** A code carries its
#   version, and its loop is drawn from what existed then:
#   - a pool of members listed here keeps only those that had joined
#     (`data::there`, `data::joined_of`) before it is drawn from, a pool the
#     core writes in Rust as well;
#   - a setting whose word a loop draws (a `[words ...]` list here) draws
#     only among the words that had joined;
#   - **a new setting drawn per loop** (as tuning.cents, progression.kind,
#     lowBell.kind and twang.kind are, each counted against a loop's
#     changes) draws nothing below its own version: its draw asks
#     `data::drawn_at` first and plays today's where that is false, on a
#     stream of its own, and it is counted only where it plays
#     (`Render::settings_changes`);
#   - a pool with no list here (floorDrop's shapes, the echo's beats, the
#     organ's stops, a kit's patterns) moves old codes when it grows: a new
#     member of one first gets a list here and the filter where it is drawn.
# - **New members go last** in their own file (data/characters.txt,
#   data/vibes.txt, data/choices.txt and the rest), as they do here: a
#   choice's place salts its streams.
# - **Removing leaves a row.** Take the member out of the core and the data
#   and write `gone` after its row's version, then a stand-in's name where
#   one fits: a member of the same list, still here, that had joined by
#   then (one later taken out too is written again here with another). An
#   older code naming it plays the stand-in; with none it goes without
#   (a vibe, a mode, a style, a voice, a choice, a setting or a word leaves
#   the request; a journey leaves the piece's to the generator), but an
#   option plays its choice's today. A choice's `[options]` and a setting's
#   `[words]` stay after it, so a code holding it can still be read. The
#   layers and the tone's parts are the format's and are never removed.
# - **A number keeps every value ever written** (`[code numbers]`): a range
#   widened widens its row, a range narrowed leaves the row as it was, and an
#   older code's number then plays the nearest the field takes today. A
#   number outside its row was written by no build and is no code.
# - **A field this build stopped writing is still read** (its tag, core/src/
#   code.rs) and set aside, never refused, and its tag is never given again.
# - **Every member is listed.** core/tests/codes.rs fails if a vibe, a
#   profile, a mood, a mode, a voice, a bass style, a choice, an option, a
#   setting or a word has no row here, or a row here that is not gone names
#   nothing.
# - A deliberate improvement to a sound that already exists changes old codes
#   too: that is allowed, and the release notes say so.
