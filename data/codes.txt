# Share codes, version 2 (queue item 105): every name a code can carry, its
# number in a code, and the version it joined. The format itself is in
# core/README.md, "Share codes"; core/src/code.rs writes and reads it, and
# core/build.rs compiles this file in.
#
# The rules, for whoever adds something (they keep old codes as they sound):
#
# - **Ids are forever.** Each row is `name id since`: the id is the name's
#   number in a code, given once and never changed, reused or taken back,
#   whatever happens to the list's order elsewhere. A new member takes the
#   next free id of its list. A member renamed keeps its id.
# - **`since` is the version it joined.** A code carries its version, and the
#   generator draws a code's loop only from what existed at that version:
#   every pool is filtered by version before its draw (`data::joined`), so a
#   newer member can't shift an older code's picks. A new member's `since` is
#   `newest` raised by one, and `newest` is raised with it, in the same change.
# - **New members go last** in their own file (data/characters.txt,
#   data/vibes.txt, data/choices.txt and the rest), as they do here: a
#   choice's place salts its streams.
# - **Every member is listed.** core/tests/codes.rs fails if a vibe, a
#   profile, a mood, a mode, a voice, a bass style, a choice, an option, a
#   setting or a word has no row here, or a row here names nothing.
# - A deliberate improvement to a sound that already exists changes old codes
#   too: that is allowed, and the release notes say so.
