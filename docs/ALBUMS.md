# Albums out for listening

Listening albums the brain has sent Mikey and not yet heard back on. Each
key is derivable from the album code itself (decode it with
`share.js decodeAlbum` and read the specs), so no key is written here.
Write a new album here when it goes out, and take it out when Mikey has
heard it: its verdict goes to `docs/DECISIONS.md` or the item it answers.

**Started fresh at 1.0 (Mikey, 2026-11-26).** No album is out. The four
albums that were out (the three in the app, Phase 3 Control, Full Room and
Lite Room) are retired, and the albums heard before 1.0 left this file.
All of them, with their codes and Mikey's verdicts, read at commit
f040b5b (`docs/ALBUMS.md` there).
